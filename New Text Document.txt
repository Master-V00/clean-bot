CLEAN BOT - RUNBOOK (organized)
===========================
Server quick start (/workspace):
  cd "/workspace/Clean bot"
  kill $(cat api.pid) $(cat bot.pid) 2>/dev/null
  chmod +x start.sh stop.sh
  ./start.sh        (starts API + discord bot)
  ./stop.sh         (stops both)
  powershell -ExecutionPolicy Bypass -File .\sync_to_server.ps1   (deploy from Windows)
  rm -rf venv .venv (cleanup if needed)

A) GPU install (CUDA):
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
  export HF_TOKEN="YOUR_HF_TOKEN_HERE"
  pip install -r requirements.txt
  pip install -e .
  pip install dotenv transformers safetensors easyocr

B) Run API server:
  export API_HOST=0.0.0.0 && export API_PORT=10100 && python3 main.py
  # alternative port:
  export API_HOST=0.0.0.0 && export API_PORT=8080 && python3 main.py
  # dev reload:
  uvicorn main:app --host 0.0.0.0 --port 10100 --reload
  # open: http://localhost:10100

C) Run discord bot:
  cd discord-bot && npm i && node index.js
  # server path:
  cd /workspace/Clean\ bot/discord-bot && npm i && node index.js

D) Port busy?
  fuser -k 10100/tcp
  curl ifconfig.me   (check public IP)

E) pcleaner extras (reference):
  CPU CLI:   pip install pcleaner
  CPU GUI:   pip install "pcleaner[gui]"
  CPU srv:   pip install "pcleaner[server,ocr,inpaint]"
  GPU full:  pip install "pcleaner[gui,gpu,ocr,inpaint]"
  CLI run:   pcleaner clean /path/to/images

F) Docker:
  CPU:  docker build -f Dockerfile.server -t panelcleaner-server:cpu .
        docker run -p 8000:8000 --env-file .env panelcleaner-server:cpu
  GPU:  docker build --target=gpu -f Dockerfile.server -t panelcleaner-server:gpu .
        docker run --gpus all -p 8000:8000 --env-file .env panelcleaner-server:gpu
  Dev:  pip install -e ".[gui,gpu,ocr,server,inpaint]"
