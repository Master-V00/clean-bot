F) Final Install / Run Commands
CPU install (CLI only):

pip install pcleaner



CPU install with GUI:

pip install "pcleaner[gui]"





CPU install with Server:

pip install "pcleaner[server,ocr,inpaint]"




GPU install (CUDA support):

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128

pip install "pcleaner[gui,gpu,ocr,inpaint]"




Full install (all features, no Paddle):

pip install "pcleaner[full]"



Docker CPU:

docker build -f Dockerfile.server -t panelcleaner-server:cpu .

docker run -p 8000:8000 --env-file .env panelcleaner-server:cpu




Docker GPU:

docker build --target=gpu -f Dockerfile.server -t panelcleaner-server:gpu .

docker run --gpus all -p 8000:8000 --env-file .env panelcleaner-server:gpu




Development install:

pip install -e ".[gui,gpu,ocr,server,inpaint]"



Run (CLI):

pcleaner clean /path/to/images


Run (Server):

uvicorn server.api:app --host 0.0.0.0 --port 8000
